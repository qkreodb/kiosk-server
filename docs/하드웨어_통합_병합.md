## 1. 병합한 변경 (파일별)

### 그대로 가져온 파일 (내가 `45c7925` 이후 손대지 않아 충돌 없음)
| 파일 | 하드웨어 변경 내용 |
|---|---|
| `app/repositories/sql_repository.py` | ① `_pid()` 가 `PRC-19` 같은 레거시 코드와 숫자 `process_id` 둘 다 처리(접두사 제거). ② 온습도/심박을 **최신 1건 직접 조회**(`ORDER BY measured_at DESC LIMIT 1`)로 변경하고 `process_name` 을 파라미터로 주입. ③ 응답에 DB의 `measured_at` 기반 **`timestamp`** 추가 |
| `app/services/sensor_service.py` | 온습도/워치 타임스탬프를 항상 `now()` 가 아니라 **DB가 준 `timestamp`** 우선 사용 |
| `app/services/space_service.py` | 기본 공정코드 `PRC-19` 폴백, **공정이 하나도 없을 때 404 대신 placeholder 공정** 생성(빈 DB graceful), temp_humid 타임스탬프 DB 값 사용 |
| `app/api/routers/cctv.py` | MJPEG 스트림 폴링을 ~10fps → **~30fps**(`1/30`), no-cache 헤더 강화 |
| `README.md` | "실제 센서 DB 모드", "라이브 CCTV 프레임 모드"(rtsp_frame.py) 실행법 추가 |

### 병합(내 변경과 공존하도록 부분 반영)한 파일
| 파일 | 반영 내용 |
|---|---|
| `app/main.py` | **`GET /kiosk.html`, `GET /kiosk`** 로 프론트를 백엔드가 직접 서빙(FileResponse). 별도 정적 서버(:8090) 불필요. 내 VLM/LED 라우터 등록·로그는 유지 |
| `app/core/config.py` | `shared_dir` → `../kiosk-hardware/frames`, `repository` 기본값 → `mysql`, `db_name` → `dasol`. (내 경광등 임계값·VLM 설정은 유지) |
| `.env` / `.env.example` | 위와 동일. **DB 비밀번호는 커밋 파일엔 넣지 않고**(아래 주의) 로컬 `.env` 에만 |
| `kiosk.html` | 받은 파일(=baseline+하드웨어)로 교체 후 **내 4가지 변경 재적용**(분석 오버레이 음성행, analyzeCurrentCam TTS/LED 피드백, countToLevel 1/2/3/4, 리셋 소등) |

### kiosk.html 하드웨어 프론트 변경 요약
- **중앙 전시홀 CCTV**: YouTube iframe 대신 `<img id="cctvImage">` 로 백엔드 `GET /cctv/stream`(MJPEG)
  표시. `isCentralCctv()` 가 "중앙 전시홀/Central Hall" 일 때만 라이브 스트림으로 전환.
- **라이브 센서 폴링**: 5초마다 `GET /sensor/temp-humid`, `GET /sensor/watch` 조회 →
  현장환경 카드 배지(TEMP/HUM/HR) 갱신. 온습도·심박 모달이 async 로 바뀌어
  **중앙 센서(TH-03 / WATCH-03)** 는 실데이터, 나머지는 더미.

## 2. 판단·주의사항 (의도적으로 다르게 한 것)

1. **DB 비밀번호(`ekthf123`)** — 받은 코드는 `config.py`/`.env.example`/`README.md` 에 평문으로
   박아두었으나, **저장소에 커밋되는 파일에는 넣지 않았다.** 실제 값은 **로컬 `.env`(gitignore)** 에만
   두었다. 커밋 템플릿(`.env.example`)은 빈 값 + 경고 주석.
2. **`requirements.txt` 버전 업** — 받은 코드는 fastapi 0.115→0.136, pydantic 2.10→2.12 등으로
   올렸으나, **현재 동작 중인 버전을 깨지 않기 위해 반영하지 않았다.** 기능 병합에는 불필요.
   필요 시 별도로 검토해 올릴 것.
3. **데모 설정 유지** — 현재 `.env` 는 시연용(`KIOSK_VLM_FORCE_MOCK=true`, 임계값 1/2/3/4,
   `KIOSK_REPOSITORY=mock`)이다. 운영 전환은 [[데모_임시설정_정리]](데모_임시설정_정리.md) 참고.
   - `config.py` 기본값은 `repository=mysql` 이지만, 로컬 `.env` 의 `mock` 이 우선하므로 데모는 그대로 동작.
