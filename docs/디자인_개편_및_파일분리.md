# 키오스크 프론트 디자인 개편 및 HTML/CSS/JS 분리

> 작업일: 2026-06-24
> 대상: `kiosk.html` (키오스크 프론트, 백엔드 PORT 8080 이 직접 서빙)

## 1. 목적

- 새 디자인(`C:\workspace\SaferKiosk`)의 **전체 레이아웃·룩앤필**을 키오스크에 반영.
- **기능은 기존 코드 그대로** 유지(백엔드 연동, VLM/TTS/경광등, 라이브 센서 등).
- 한 파일에 모여 있던 거대한 `kiosk.html`(약 5,500줄)을 **HTML / CSS / JS 로 분리**.
- 모달이 연결되지 않았던 버튼 4종을 기존 모달에 연결(디자인은 새 디자인 기준).

## 2. 변경 전/후 구조

### 변경 전
- `kiosk.html` 단일 파일(HTML + `<style>` + `<script>` 모두 인라인, 다크 테마).

### 변경 후 (파일 분리)
```
kiosk.html              ← 새 디자인 마크업 (SaferKiosk/index.html 기반)
css/
  design-system.css     ← 새 디자인 토큰(변수)·리셋 (라이트 테마)
  style.css             ← 새 디자인 본 스타일
  integration.css       ← [신규] 기능 위젯 보강 스타일(아래 4절)
js/
  app.js                ← 새 디자인 동작(시계/모달/CCTV/시설/MSDS 등 정적·UI)
  backend.js            ← [신규] 백엔드(PORT 8080) 연동 계층(아래 3절)
images/                 ← 새 디자인 이미지(man/map/btn_*/icon_* 등)
```

- `kiosk.html` 의 자산 경로는 상대경로(`css/…`, `js/…`, `images/…`).
- `app/main.py` 에서 `/css`, `/js`, `/images` 를 **StaticFiles 로 마운트**해 상대경로가 그대로 해석되도록 함. `kiosk.html` 은 기존처럼 `/kiosk.html`·`/kiosk` 로 서빙.

## 3. 기능 보존 — `js/backend.js` (신규)

새 디자인의 `app.js` 는 정적/더미 동작만 담고 있어, 기존 코드의 **실서버 연동 기능**을
별도 계층으로 옮겨 `app.js` 다음에 로드한다. 일부 함수는 실서버 버전으로 덮어쓴다(`window` 재할당).

연동 엔드포인트:

| 기능 | 호출 | 비고 |
|------|------|------|
| 신호등 행렬 갱신 | `GET /space-name` | `count → 등급(관심/주의/경고/위험)` 변환 · **2초 자동 폴링**(기본 점등값 없음) |
| 공정 드롭다운 채우기 | `GET /space-name` | 실제 DB 공정 목록으로 커스텀 드롭다운 구성 |
| 카운트 초기화 | `POST /behavior/reset` | 즉시 소등 + 서버 0 리셋 |
| VLM 분석 | `POST /vlm/infer` | 체크된 감시대상(`detect_actions`) 전송, 결과 오버레이 |
| TTS 데모 | `POST /tts/demo` | CCTV [TTS] 버튼 |
| 경광등 점등 | `POST /led/trigger` | 신호등 헤더 관심/주의/경고/위험 클릭 |
| 라이브 온습도 | `GET /sensor/temp-humid?sensor_name=sonoff_1` | 하단 배지 **2초 폴링**(sonoff) + 센서 상세 모달 |
| 라이브 심박 | `GET /sensor/watch` | 하단 배지 **2초 폴링** + 심박 모달 |
| 중앙홀 CCTV | `GET /cctv/live` | IP카메라 RTSP→MJPEG 중계(`#cctvImage`) |

추가로 연결 상태 배지·라이브 센서 배지·토스트 알림도 이전.

### 새 디자인 DOM 에 맞춘 핵심 적응
- **공정 선택**: 기존은 `<select>` 였으나 새 디자인은 커스텀 드롭다운(`.bps-option`).
  `currentProcessCode()` / `populateProcesses()` 를 `.bps-option`(`data-code`) 기준으로 재작성.
  옵션 선택(`bhPickProc`) 시 행렬도 함께 갱신하도록 훅 추가.
- **감시대상 체크박스**: 새 디자인 행렬에는 없던 `.bhm-focus-cb`(`data-focus-key`/`data-focus-label`)를
  4개 행에 추가 → VLM `detect_actions` 수집에 사용(`hat/touch/dangerInOut/ladder_action`).
- **경광등 트리거**: 행렬 헤더의 관심/주의/경고/위험 라벨을 클릭 가능한 `.bhm-led-btn` 으로 만들어 `triggerLed()` 연결.
- **CCTV 모달**: 헤더에 [TTS]/[분석] 버튼, 화면에 VLM 결과 오버레이(`#cctvVlmOverlay`)와 IP카메라 이미지(`#cctvImage`) 추가.

## 4. 기능 보강 스타일 — `css/integration.css` (신규)

새 디자인 본 스타일에 없는, 기능 요소들의 스타일만 담음(색상은 새 디자인 라이트 테마 변수 사용):
- 감시대상 체크박스(`.bhm-focus-cb`)·항목 힌트
- 경광등 점등 버튼(`.bhm-led-btn`, 클릭/점등 상태)
- CCTV [TTS]/[분석] 버튼·VLM 결과 오버레이·IP카메라 이미지
- 라이브 센서 배지·백엔드 연결 배지·토스트

## 5. 모달 없던 버튼 4종 연결

하단 사각 버튼 중 onclick 이 없던 것들을 **기존 기능 모달**에 연결(디자인은 새 디자인 모달 사용):

하단 사각 버튼은 현재 **4개**(`grid-template-columns: repeat(4,1fr)`):

| 버튼 | 연결 함수 | 모달 |
|------|-----------|------|
| 공정관리 | `openProcessMgmt()` | `#processOverlay` |
| 현장특이사항 | `openIssueMgmt()` | `#issueOverlay` (탭: 공정특성·위험성평가 / 현장 특이사항) |
| 안전보건경영방침 | `openPolicy('management')` | `#policyOverlay` (문서형) |
| 산업안전보건 법령요지 | `openPolicy('law')` | `#policyOverlay` (표) → 행 클릭 시 `#lawDetailOverlay` |

> **MSDS 버튼 제거**: 별도 목록 모달(`openMSDSList`, `#msdsListOverlay`)을 삭제하고, 공정관리 상세의 사용물질 클릭 → `openMSDS(물질명)` → `#msdsOverlay` 흐름으로 통합.
> **위험성평가 버튼 제거**: 현장 통합 관리 모달(`#issueOverlay`)의 "공정명·공정코드" 탭에 위험성평가가 인라인 통합되어 별도 버튼이 불필요해짐(2026-06-29). 자세한 내용은 `진행상황.md` 섹션 15 참고.

> 새 디자인에 이미 동일 ID 의 모달과 핸들러가 styled 상태로 존재하여, 버튼의 onclick 만 연결.
> 경영방침/법령요지는 새 디자인의 통합 `policyOverlay` + `openPolicy(type)` 를 사용(요청대로 새 디자인과 유사한 형태).

## 6. `app/main.py` 변경

- `from fastapi.staticfiles import StaticFiles` 추가.
- 라우터 등록 뒤 `/css`, `/js`, `/images` 디렉터리를 존재할 때만 마운트.
- `kiosk.html` 서빙(`/kiosk.html`, `/kiosk`)은 기존과 동일.

## 7. 검증

로컬 기동(`uvicorn app.main:app --port 8080`) 후 확인:
- `GET /kiosk.html`, `/css/*.css`, `/js/*.js`, `/images/*` → 모두 200
- `GET /space-name`(+`?process_code=PRC-19`), `POST /behavior/reset`, `GET /sensor/temp-humid`, `GET /sensor/watch` → 200
- 응답 스키마(`processes`/`process`/`behaviors[].count`, `workers[]` 키)가 프론트 기대와 일치 확인
- 주입 요소(체크박스/LED 버튼/분석 버튼/VLM 오버레이/cctvImage/버튼 onclick) 서빙 HTML 에 존재 확인

## 8. 참고 / 후속

- `app.js`(디자인) → `backend.js`(연동) 순서로 로드되며, 인라인 onclick 이 호출하는 함수는 `window` 에 노출.
- 외부 폰트/아이콘(Pretendard·Google Fonts·Remixicon)은 CDN 사용(오프라인 시 폰트만 폴백).
- 추후 디자인 갱신 시 `css/style.css`·`images/` 만 교체하고, 기능은 `backend.js`·`integration.css` 로 유지하면 됨.
