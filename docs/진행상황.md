## 1. 구축 범위 (무엇을 만들었나)

다이어그램의 **Kiosk Back section** 한 대만 구현했습니다. 이 서버의 역할은 세 가지입니다.

1. **Shared DB 조회** — 하드웨어 서버가 수집·기록한 데이터를 읽음 (현재는 mock).
2. **Shared Dir 프레임 읽기** — 하드웨어 서버가 기록하는 30fps 프레임을 키오스크 화면용으로 제공.
3. **VLM 서버 `/infer` 호출 + 후처리** — TTS(스피커) + DB 카운팅 + 경광등 제어 신호 생성.

### 구현하지 **않은** 것 (외부 서버이므로)

- ❌ **Hardware Server (PORT 8081)** — `002.png` 참고용. RTSP/MQTT/센서/워치 등.
- ❌ **VLM Server (PORT 8000)** — Jetson Thor의 Qwen2.5 VLM/LLM. **클라이언트만** 구현.
- ❌ **실제 DB 스키마** — 아직 설계 전이므로, 인터페이스 뒤의 mock(JSON/in-memory)으로 대체.

## 2. 아키텍처 (계층 구조)

의존 방향은 한 방향입니다.

```
router → 요청 검증(Pydantic) → service → repository / integration → 응답 DTO
```

- **router** : 비즈니스 로직 없음. 입력 검증과 응답만.
- **service** : 비즈니스 로직 (VLM 파이프라인 오케스트레이션 포함).
- **repository** : 데이터 접근(Shared DB seam). 현재 mock 1종.
- **integration** : 외부 I/O (VLM 클라이언트, TTS, Shared Dir, 액추에이터). 전부 stub 가능.
- **schemas** : 도메인별 Pydantic DTO.
- **domain** : 4대 불안전행동 카테고리, 경광등 상태 등 상수/enum.

```
app/
  main.py                 # 앱 팩토리, CORS, 라우터 등록, lifespan, /health
  core/config.py          # 모든 설정을 env/.env 한 곳에서 로드
  core/logging.py
  domain/constants.py     # 4대 불안전행동 카테고리, 경광등 상태
  schemas/                # space / sensor / modal / vlm / common DTO
  repositories/           # base 인터페이스 + mock 구현 + factory(DB 교체 지점)
  integrations/           # vlm_client / tts / shared_dir / actuators
  services/               # space / sensor / modal / cctv / vlm 서비스
  api/routers/            # space / sensor / modal / cctv / vlm / health
mock_data/                # Shared DB 행을 모사한 JSON 픽스처
docs/진행상황.md          # (이 문서)
```

- 보너스: `/cctv/stream` 는 MJPEG-over-HTTP 연속 스트림.

## 4. VLM 추론 파이프라인 (001.png 우측 흐름)

`POST /vlm/infer` 호출 시:

1. **VLM 서버 호출** — `vlm_client` 가 외부 VLM `/infer`(기본 `http://localhost:8000`)에 POST.
   응답은 `{ "탐지": "...", "위험 경고 텍스트": "..." }` 형태. 서버 오프라인/실패 시 **내장 mock** 으로 폴백.
2. **Branch A — TTS 텍스트 추출**: `위험 경고 텍스트` → Edge TTS 음성 변환 → **스피커**(액추에이터, stub).
3. **Branch B — DB 텍스트 추출 + 경광등**:
   - `탐지` 값을 키워드로 파싱 → 4대 불안전행동 카테고리로 분류(`파싱 & DB 반영`).
   - 해당 카테고리 카운트 **+1** (mock DB).
   - 반영 후 카운트 **조회**.
   - 카운트 → **경광등 제어 신호 생성**(임계값 기반). 예: count 3 → `노란색 볼 깜빡임`.
   - 신호를 **경광등**(액추에이터, stub)으로 전송.
4. **응답 결합**: 탐지/경고문/카테고리+카운트/경광등 신호/TTS 상태를 한 JSON으로 반환.

### 경광등 임계값 (설정값, 튜닝 가능)
| 누적 카운트 | 상태 | 한글 제어 신호 |
|---|---|---|
| 0 | off | 소등 |
| 1 ~ 2 | green | 녹색 점등 |
| 3 ~ 4 (`KIOSK_LIGHT_CAUTION_THRESHOLD=3`) | yellow_blink | **노란색 볼 깜빡임** |
| 5+ (`KIOSK_LIGHT_DANGER_THRESHOLD=5`) | red_blink | 빨간색 볼 깜빡임 |

### 4대 불안전행동 카테고리 (프론트 슬라이드와 동일)
| id | 이름 | 기본 등급 | 파싱 키워드(예) |
|---|---|---|---|
| `helmet_off` | 모자(안전모) 벗는 행동 | 위험 | 안전모, 헬멧, helmet |
| `touch_equipment` | 스피커(설비) 만지는 행동 | 주의 | 설비, 스피커, 만지 |
| `unauthorized_crossing` | 위험지역 무단횡단 행동 | 정상 | 무단횡단, 위험지역, 출입 |
| `ladder_alone` | 사다리 혼자 올라가는 행동 | 정상 | 사다리, 단독, ladder |

## 5. 무엇이 mock 이고, 실제 연동은 어디에 끼우나

| 대상 | 현재 (mock) | 실제 교체 지점 |
|---|---|---|
| **Shared DB** | ✅ **MySQL 연동 완료** (`repositories/sql_repository.py`, PyMySQL). `KIOSK_REPOSITORY=mysql` 로 전환, 실패 시 mock 폴백 | 쿼리/매핑은 `sql_repository.py`, 연결설정은 `core/config.py` `KIOSK_DB_*`. ERD 외 데이터는 `dummy_data.py` |
| **VLM 서버** | `integrations/vlm_client.py` 오프라인 stub | `KIOSK_VLM_BASE_URL` 설정 → 실제 `/infer` 로 POST |
| **TTS 재생** | Edge TTS로 파일 합성, 스피커는 로그 stub | `integrations/actuators.py::SpeakerActuator.play` |
| **경광등** | `WarningLightActuator` 로그 stub | GPIO/릴레이/시리얼 출력으로 교체 |
| **Shared Dir** | 프레임 없으면 placeholder JPEG | `KIOSK_SHARED_DIR` 를 실제 프레임 디렉터리로 |

모든 설정은 `app/core/config.py`(env 접두사 `KIOSK_`)에 집중. `.env.example` 참고.

### 8-2. 백엔드 변경사항

#### 새 엔드포인트: `POST /behavior/reset`

```http

Content-Type: application/json

Response 200:
{ "reset": true, "process_code": "PRC-19" }
```

- 분석 중 버튼 비활성화, 완료/실패 후 복구.

| `hydrateMatrix(processCode)` | `GET /space-name` → `#bhMatrix` 행렬 실시간 갱신 |
| `window.resetBehavior` | 기존 함수 교체 (UI + 백엔드 리셋) |
| `analyzeCurrentCam()` | VLM POST + 결과 오버레이 표시 (기존 JS `<script>` 블록 내 정의) |
| `init()` | 페이지 로드 시 최초 행렬 갱신 + 공정 드롭다운 이벤트 연결 |
| 연결 배지 | 상단 고정 배지 — 백엔드 온라인/오프라인 상태 표시 |

#### ④ count → 4단계 등급 변환 기준

| count | 등급 | 색상 |
|---|---|---|
| 0 | 관심 (interest) | 초록 |
| 1 ~ 2 | 주의 (caution) | 노랑 |
| 3 ~ 4 | 경고 (warning) | 주황 |
| 5 이상 | 위험 (danger) | 빨강 |
