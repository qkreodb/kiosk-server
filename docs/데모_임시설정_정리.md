## B. VLM 실연동 완료로 "더 이상 필요 없어진 것" (삭제 후보)

### B-1. [TTS] 데모 버튼 — 스톱갭, 삭제 권장
VLM 개발자 부재로 TTS만 따로 시연하려고 넣은 하드코딩 버튼. 이제 [분석] 버튼이
실제 경고문을 TTS로 재생하므로 **중복/불필요**. 운영 전 제거 권장.

삭제 대상:
- `app/api/routers/tts.py` — `/tts/demo` 라우터 + `_DEMO_MESSAGES`(하드코딩 4문구)
- `app/main.py` — `tts.router` import 및 `app.include_router(tts.router)` 등록
- `kiosk.html`:
  - `playTtsDemo()` 함수
  - `[TTS]` 버튼 마크업(`id="cctvTtsBtn"`, `onclick="playTtsDemo()"`)
  - `.cctv-tts-btn` CSS

> 참고: TTS **기능 자체**(`app/integrations/tts.py`, `SpeakerActuator`)는 [분석] 파이프라인이
> 사용하므로 **삭제하면 안 됨**. 삭제 대상은 "데모 버튼" 한정.

### B-2. mock 시드/더미 데이터 — 실제 DB 사용 시 불필요
운영에서 `KIOSK_REPOSITORY=mysql` 로 전환하면 아래 mock 자원은 사용되지 않는다(파일은
오프라인 개발 폴백용으로 남겨둘 수 있음, 단 시연 데이터로 오인 주의):
- `mock_data/behavior_seed.json` (공정별 시드 카운트 — 예: PRC-19 helmet_off=3)
- `app/repositories/mock_repository.py`, `app/repositories/dummy_data.py`

### B-3. VLM 오프라인 mock 시나리오 — 폴백용(유지 가능)
- `app/integrations/vlm_client.py` 의 `_MOCK_SCENES` — `FORCE_MOCK=true` 또는 Jetson
  연결 실패 시 사용되는 가짜 감지. **A-1을 false로 되돌리면 평소엔 호출되지 않음**.
  네트워크 장애 폴백으로 유지해도 무방.

## C. 삭제하면 안 되는 것 (혼동 방지)

데모 중 임시로 보이지만 **실제 기능**이므로 그대로 둘 것:
- `app/services/led_service.py`, `warning_light_control/` — 실물 경광등 제어(핵심)
- `app/integrations/actuators.py` `SpeakerActuator.play_async` — 분석 TTS 재생
- 신호등 카드의 **관심/주의/경고/위험 칸 수동 버튼**(`triggerLed`) — 점검/시연용으로 유용.
  운영 정책상 불필요하다고 판단되면 그때 제거 검토(필수 삭제 아님).
